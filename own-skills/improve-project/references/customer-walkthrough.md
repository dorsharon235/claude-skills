# Customer walkthrough — how to "be the customer"

## 1. Pick personas (2–3)
Base them on phase 1 (who the customer really is). Examples:
- **ראשון בטלפון**: never heard of the product, on a phone, 30 seconds of patience, Hebrew speaker.
- **חוזר וממהר**: knows what they want, wants it in the fewest clicks.
- **מבוגר / משתמש קורא מסך**: larger text, keyboard or screen reader, low tolerance for clutter.
- **ילד** (games): reads little, clicks everything, gets bored fast.
- **מקבל ההחלטה** (B2B / committee / manager): wants to trust the numbers and decide.

Write each persona in 2 lines: who, what they want to achieve, what would make them leave.

## 2. Define the journeys
The 3–5 things customers come to do (e.g. understand the offer → contact; sign up → first success; search → buy; open game → first fun moment in under a minute).

## 3. Walk each journey for real
For each persona × journey:
1. Start where the customer starts (home page, link from WhatsApp, search result, game lobby).
2. Desktop 1440px AND mobile 375px. Light and dark mode if supported. RTL check.
3. At every step take a screenshot and note:
   - מה הלקוח רואה קודם (first thing the eye lands on)
   - האם ברור מה לעשות עכשיו
   - כמה זמן / קליקים לקח
   - רגש: 🙂 בטוח · 😐 מהסס · 😣 מתוסכל · ❌ נתקע
4. Try to break it like a real person: empty form submit, wrong email, very long name, back button, refresh mid-flow, slow network, double click, Hebrew + English mixed text, emoji.
5. Read the copy aloud in your head. Would a normal Israeli customer understand it without explanation?
6. Check trust signals: who is behind this, contact, privacy, real photos, prices clear.

## 4. Score
For each journey give: הצלחה (כן/חלקית/לא), זמן, נקודת החיכוך הכי גדולה.
Overall first-impression score 1–10 with one sentence why.

## 5. Non-web projects
- **Roblox / game**: play the first 5 minutes as the persona (simulator, Studio play mode, or reading the client scripts step by step). Is the goal clear in 10 seconds? First reward in under a minute? Mobile controls? Text readable on a phone?
- **Video**: watch at real speed, then frame by frame at key moments. Hook in 3 seconds? Text readable on a phone? Audio balanced? Captions?
- **Document / deck**: read as the target reader. Main message on page 1? Can it be skimmed?
- **Bot / CLI**: run the real commands a new user would type. Are errors understandable?
