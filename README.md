# Dor Sharon's Claude skills

A list of the Claude skills I use. Nothing is copied here - every skill installs straight from its author's GitHub repo.

## Install (in Claude Code)

```
/plugin marketplace add dorsharon235/claude-skills
```

Then install any of these, or pick them from the `/plugin` menu:

```
/plugin install emilkowalski-skills@dor-sharon
/plugin install hyperframes@dor-sharon
/plugin install brag@dor-sharon
/plugin install taste-skill-classic-b9ca2fd@dor-sharon
/plugin install taste-skill@dor-sharon
/plugin install taste-skill-classic-a206bbf@dor-sharon
/plugin install impeccable@dor-sharon
```
